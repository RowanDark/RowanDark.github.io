Tools

open-source security tooling under active development

These are open-source tools built and maintained in-house at Rosec Cyber, written primarily in Go and Rust, and used directly on client engagements for recon, enumeration, and secret scanning. Source is public on github.com/RowanDark.

ls ~/tools/
SASA active

Port scanner built for low-noise recon. Designed to minimize detection footprint during active engagements while maintaining accuracy across common service ports.

Rust CLI recon
github.com/RowanDark/SASA
rezz active

A web crawler and secret scanner for authorized security testing. Crawls target sites using either a headless Chromium browser or a lightweight HTTP client, scans discovered pages and scripts for secrets and sensitive data using embedded regex pattern kits, and maps all reachable endpoints.

Go recon framework
github.com/RowanDark/rezz
v0x active

A modern web wordlist generator written in Go. Conceptually similar to CeWL but with headless browser support, structured output formats, and optional authentication.

Go OSINT recon
github.com/RowanDark/v0x
scion active

Scion is a passive reconnaissance tool for discovering subdomains and related domains associated with a target. It aggregates results across multiple public certificate transparency logs, DNS datasets, and optional API-backed sources -- then deduplicates, optionally validates and outputs in your format of choice.

Go recon OSINT
github.com/RowanDark/scion
indago active

Fast, modular OSINT aggregator for CLI-first recon workflows. Queries multiple open-source intelligence sources concurrently and normalizes results through a clean module interface.

Go OSINT recon
github.com/RowanDark/indago
KiteString active

Context-aware API endpoint discovery and path fuzzing for modern web applications. Probes APIs using structured wordlists and HTTP method/header context rather than blind directory fuzzing.

Go API recon
github.com/RowanDark/KiteString

Snippets

reference one-liners, tool invocations, and output captures
cat snippets/index.txt
sasa — stealth port scan bash 
# fast scan, common ports
sasa $TARGET

# full port range
sasa --ports 1-65535 $TARGET

# output to file
sasa --output results.txt \
  $TARGET
scion — subdomain enum bash 
# basic enumeration
scion example.com

# subdomains only, pipe to httpx
scion --subs-only example.com \
  | httpx -silent

# dns-validate results
scion --verify \
  --output json \
  --out-file results.json \
  example.com
scion — diff & scope filter bash 
# save baseline run
scion --output text \
  --out-file baseline.txt \
  example.com

# later: show only new assets
scion --compare baseline.txt \
  example.com

# filter to in-scope only
scion --scope-file scope.txt \
  example.com
scion — nuclei chain bash 
# validate then scan exposures
scion --subs-only \
  --verify example.com \
  | nuclei -t exposures/

# check available sources
scion --list-sources

# specific sources only
scion \
  --sources crtsh,securitytrails \
  example.com
rezz — secret scan bash 
# default scan (api-keys, creds, headers)
rezz --url https://example.com

# all pattern kits, json output
rezz --url https://example.com \
  --no-headless \
  --patterns all \
  --format json \
  --output findings.json

# summary after scan
rezz --url https://example.com \
  --summary
rezz — authenticated scan bash 
# form-based login
rezz \
  --url https://example.com/dashboard \
  --auth-form-url https://example.com/login \
  --auth-form-user admin \
  --auth-form-pass hunter2

# cookie injection
rezz --url https://example.com \
  --auth-cookie \
  "session=abc123; csrf=xyz"
rezz map — endpoint mapper bash 
# map all reachable endpoints
rezz map \
  --url https://example.com \
  --format json \
  --output endpoints.json

# scope to specific hosts
rezz map \
  --url https://example.com \
  --scope example.com,api.example.com \
  --verbose
v0x — wordlist gen bash 
# basic crawl to stdout (CeWL-compatible)
v0x --url https://example.com

# depth 3, json output
v0x --url https://example.com \
  --depth 3 \
  --format json \
  --output wordlist.json

# static mode, markdown report
v0x --url https://example.com \
  --no-headless \
  --format md \
  --output report.md
v0x — authenticated crawl bash 
# form login with verify selector
v0x \
  --url https://example.com/dashboard \
  --auth-form-url https://example.com/login \
  --auth-form-user admin \
  --auth-form-pass hunter2 \
  --auth-verify-selector "#account-menu"

# bearer token
v0x --url https://api.example.com \
  --auth-bearer $TOKEN

Tools in action

real captured output, not staged screenshots

rezz — secret scanner

A run against a deliberately vulnerable practice target, surfacing hardcoded financial data, an exposed Google API key, and a Bitcoin address left in page source — the class of leftover secret that manual review misses and rezz is built to catch.

v0x — wordlist generator

A depth-2 crawl of the same practice target, walking every discovered page and query parameter to build a site-specific wordlist — the kind of targeted input list that outperforms a generic dictionary during content discovery.

scion — subdomain enumeration

A passive enumeration pass across ten OSINT sources for a single domain, returning 261 unique results in 30 seconds — the map an attacker builds before touching anything, done here before they do.
